# Nightmares Reimagined: The Book of Secrets
*"Your enemy learns. Your book remembers."*

A browser horror adventure: HTML5 Canvas, ES modules, procedural Web Audio (no audio files), browser text-to-speech voices with subtitles, and localStorage for progress and the adaptive "Living Nightmare" enemy memory. No backend.

## Run locally
Serve the `public/` folder with any static server (ES modules need http):
```
npx serve public    # or: python3 -m http.server -d public 8000
```
Controls: WASD/arrows move · Shift run · E interact/hide · F flashlight · Q throw · Space hold breath · Esc pause · M mute.

## Living Nightmare
Hides, hiding spots, flashlight time, noise, detections, distractions and choices are saved. The hotel creature weights its searches toward your most-used hiding spots and listens longer there, notices you further away if you rely on the flashlight, and starts ignoring distractions you overuse.
